# Sistema de diseño

## Colores
- `--bg`: `#f8f4ea`
- `--panel`: `#fffdf7`
- `--ink`: `#1b1f23`
- `--muted`: `#6f7681`
- `--primary`: `#0f8b8d`
- `--primary-strong`: `#0a5e61`
- `--accent`: `#ff7f11`
- `--danger`: `#c1292e`
- `--line`: `#ddd5c5`

## Tipografía
- Fuente principal: `Space Grotesk`.
- Titulo: `clamp(1.5rem, 3.6vw, 2.2rem)`.
- Texto base: `1rem`.
- Texto secundario: `0.95rem`.

## Espaciado
- Escala base: `4px`.
- `xs`: `4px`
- `sm`: `8px`
- `md`: `16px`
- `lg`: `24px`
- `xl`: `32px`

## Componentes base
- `Input de tarea`: borde suave, foco visible, max 500 caracteres.
- `Boton primario`: fondo `--primary`, hover `--primary-strong`.
- `Boton secundario`: fondo transparente, borde `--line`.
- `Boton peligro`: fondo `--danger` para eliminacion.
- `Fila de tarea`: tarjeta con checkbox, texto y acciones.
- `Tabs de filtro`: estado activo con `--accent`.
- `Mensaje de error`: color `--danger` con texto legible.
